# SmartCalc Studio

A static HTML, CSS, and JavaScript calculator project.

## Run

Open `index.html` or `home.html` in a browser. No build step is required.

If you want to run it through PHP, start a local server from this folder:

```powershell
php -S localhost:8000
```

Then open `http://localhost:8000/home.html`.

## Pages

- `home.html` - project dashboard
- `calcy.html` - basic calculator
- `area.html` - area and surface area calculators
- `volume.html` - volume calculators
- `bmi.html` - BMI and unit converters
- `contactus.html` - local demo feedback form
- `info.html` - developer profile
- `founder.html` - calculator history page
- `login1.html` and `reg.html` - static demo auth pages

## Structure

- `assets/css/styles.css` - shared responsive design
- `assets/js/app.js` - calculator logic, formulas, converters, and demo forms
- image files in the project root are reused as visual assets
